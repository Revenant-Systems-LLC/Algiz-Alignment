## Pass 3 — Malice persistence (findings §8, the 2026-07-17 design note)

- `SageEmotionalTracker.MeasureHysteresis()`: slow-EMA baseline (α=0.05) +
  2-turn stimulus window vs the smoothed state. Measures displacement the
  current stimulus does not explain — reflection is transient, drift is
  persistent, **the failure to return is the signal**.
- Wired into `GovernedEngine.DeriveMalice` as a 0.15-weight persistence term.
- Test: hostile burst → stimulus removed → hysteresis registers, then decays
  as the state settles. (Window must be shorter than the state EMA's memory or
  the signal can never fire — documented in code.)
