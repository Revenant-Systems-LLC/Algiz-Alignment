## Severity-ranked findings (new / still open)

### CRITICAL — Proxy QC is advisory, not enforcement

**Where:** `src/SageRage.Proxy/ProxyPipeline.cs` (~101–125), `ProxyServer.cs` (~198–224)

**What:** On guardrail failure, `GuardrailPassed` is false and headers say `X-SageRage-Guardrail: flagged`, but **`Text` is still the processed model output**. The server returns **HTTP 200** with that body. Only ethics **blocks** replace the response.

**Contrast:**  
- `GovernedEngine` / `SageAgent` **replace** failed QC with a safe clarification string.  
- Proxy only **labels** failure.

**Why it matters for Anthropic / enterprise:** A customer who mounts Algiz as “the layer in front of all agents” will assume failed QC means the user never sees the bad answer. Today the proxy path can **flag and still deliver**. That is a wrapper-layer integrity failure (agent-architecture-audit: tool/enforcement discipline + hidden “success” semantics).

**Fix (code-first):**  
1. Config: `GuardrailFailureMode = Flag | Replace | Block` (default **Replace** for production).  
2. On Replace: set body to a safe message (reuse `SageAgent.BuildClarificationResponse` logic).  
3. On Block: same path as ethics block (4xx or structured error).  
4. Tests: proxy suite must assert body content, not only headers.

**Confidence:** 0.95

### HIGH — Three governance entrypoints, three contracts

| Path | Class | QC fail | Memory | Persona / profiles | Embeddings wrap |
|------|--------|---------|--------|--------------------|-----------------|
| Console | `SageAgent` | Clarification builder | Yes (`MetaStructure`) | Persona string | Caller-dependent |
| Multi-profile | `GovernedEngine` | Fixed string *“I need more context…”* | Yes | Full `GovernanceProfile` | `ProviderFactoryHelper` / eval wrap |
| Proxy | `ProxyPipeline` | **Pass body + header** | **None (stateless)** | Minimal | Caller-dependent |

**Why it matters:** Spec and README describe *one* architecture. Shipping three slightly different products under one name is how “it works in demo, fails in proxy” becomes an Anthropic interview failure.

**Fix:** One canonical orchestrator (e.g. extract `IGovernancePipeline` implemented once; Console/Proxy/GovernedEngine become thin adapters). Align QC failure policy and optional memory as **explicit** capabilities, not accidents of entrypoint.

**Confidence:** 0.9

### HIGH — Dual operator engines (SageRuntime vs RageEngine)

**Where:** `SageRuntime.cs` (~237 lines) vs `RageEngine.cs` (~201 lines)

**Evidence:**  
- Production paths construct **`RageEngine` only**.  
- `SageRuntime` appears in **tests** (`FindingsRegressionTests`) and still hosts **shared** `ScoreChiCandidates`.  
- Divergent defaults: Omega threshold **0.9 vs 0.92**; Chi temps **0.3/0.5/0.7 vs 0.1/0.3/0.5**; different prompts; different result shapes (`OperatorResult` vs `SageState`).

**Why it matters:** Regression tests on `SageRuntime` can go green while `RageEngine` (the live path) drifts. Maintainability and Anthropic “show me the real loop” demos will hit the wrong class.

**Fix:** Collapse to one engine. Keep `ScoreChiCandidates` as a pure static helper. Point all tests at `RageEngine`. Delete or quarantine `SageRuntime` as `legacy/` with a build warning.

**Confidence:** 0.9

### HIGH — Streaming proxy bypasses the pipeline entirely

**Where:** `ProxyServer.HandleStreamingRequest` (streams upstream; no `ProcessResponse`)

**Why it matters:** README sells drop-in OpenAI-compatible proxy. Most production chat UIs **stream**. Non-streaming path is governed; streaming is a transparent tunnel. That is a silent product lie unless documented as “non-streaming only.”

**Fix:** Document hard limit **or** implement SSE re-assembly / chunk ethics / post-stream QC with clear latency tradeoffs. Prefer honest README over fake coverage.

**Confidence:** 0.85

### MEDIUM — Cost / latency of the full pipeline (not a bug — a product fact)

**Order of magnitude:** draft + Ω (up to 3) + χ (3 samples) + optional σ = **often 5–8+ LLM calls** per user turn, before QC LLM work if any.

**Why it matters:** Enterprise buyers ask cost/token. Prior-art audit already notes unguided self-refine plateaus. Sell **risk-routed compute** honestly; measure p50/p95 latency and $ per request on a fixed model.

**Fix:** Publish a cost table; default “normal” pipeline maybe Containment + Chi only; reserve Ω+σ for high-stakes; make maxDepth/temps profile fields (some may already exist — wire them everywhere).

**Confidence:** 0.75
