## Tier 0: Atomic Primitives (10 fundamentals)
These CANNOT be defined using other primitives:
1. Ω (Recursion)
2. Ξ (Meta-structure)
3. ↦ (Transformation)
4. ∅ (Absence)
5. χ (Coherence)
6. = (Equality)
7. ≠ (Difference)
8. [...] (Containment)
9. → (Sequence)
10. σ (Skeptical Contrast Operator)

## Operator Domain / Codomain
All operators execute over a common runtime state:
`State { Text, Emotion, Coherence, Entropy, SimilarityToInput, Memory, Ethics, Trace }`.

- Input domain: `State`
- Output codomain: `State`
- Composition `(A ∘ B)` means execute `B(state)` then `A(state)`.

## Tier 1: Derived Operators
Built from Tier 0 composition:
- ∂ := (Ω ∘ [...])
- μ := (↦ ∘ [≠, =] ∘ [...])
- ι := (= ∘ ↦)

## Tier 2: Domain Compounds
Built from Tier 1 for specific applications:
- Λυ_s (Veracity)
- Λγ_s (Gravitas)
- Λρ_s (Resonance)

## Simplification Principle
When teaching SAGE-RAGE:
- **Novice**: Start with "The Big 5" (Ω, Ξ, ↦, ∅, χ) as conceptual anchors
- **Practitioner**: Add full Tier 0 (10 primitives) for actual usage
- **Architect**: Master all three tiers for system design
